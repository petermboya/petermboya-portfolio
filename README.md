# Peter Mboya and Godwin Gatere | Portfolio

A single-page personal portfolio built with plain HTML, CSS, and JavaScript.

**Live demo:** https://petermboya.github.io/petermboya-portfolio/

## Features

- Sticky header with links that jump to each section
- Testimonials stored in a JavaScript object and rendered with a loop
- Project cards (title, description, tech used) rendered from an array of objects
- Contact section with email and GitHub links
- Responsive layout that works on phones, tablets, and desktops
- Visible keyboard focus and reduced-motion support

## Technologies Used

- HTML5
- CSS3 (custom properties, flexbox, grid, media queries)
- JavaScript (objects, arrays, loops, DOM manipulation)
- Git and GitHub Pages

## Run It Locally

1. Clone the repo:
   ```
   git clone https://github.com/petermboya/petermboya-portfolio.git
   ```
2. Open the folder:
   ```
   cd petermboya-portfolio
   ```
3. Open `index.html` in your browser. No build step or install needed.
